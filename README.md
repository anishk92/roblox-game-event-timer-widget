## Features

- Shows live Roblox game events.
- Shows upcoming Roblox game events.
- Live countdown timers that update every second.
- Displays game names, event titles, and images.
- Links each game to its TechBoltX game page.
- Automatically refreshes event data.
- Responsive design for desktop and mobile.
- Free to embed on your website.
- No installation required.

## Embed the Widget

Add this iframe code to your website:

```html
<iframe
  src="https://anishk92.github.io/roblox-game-event-timer-widget/"
  title="Roblox Live and Upcoming Events"
  width="100%"
  height="900"
  loading="lazy"
  style="border:0;border-radius:12px;">
</iframe>
```

You can change the height to fit your website.

## Event Data

The widget gets its event data from the TechBoltX public API.

API endpoint:

https://techboltx.com/wp-json/techboltx/v1/roblox-events

The API provides live and upcoming event information. The widget uses this data to display event cards and countdowns.
